---
name: add-text
description: Add or change user-visible text in Topo Heli in all five languages (English, Dutch, German, Serbian Latin, Serbian Cyrillic). Use for any new or changed UI string.
---

All UI texts live in `src/i18n.ts`:

- `en` defines the keys (`StringKey`); add the same key to `nl`, `de` and `srLatn` (TypeScript fails otherwise).
- Serbian is written once, in Latin script (ekavian, informal *ti*); Cyrillic is generated by
  transliteration. Never add a separate Cyrillic text.
- Transliteration skips HTML tags, `{params}` and `&entities;`. Anything that must stay as-is in
  Cyrillic (Dutch terms such as *basislijst topografie*, brand names, place names) goes in as a
  `{param}` filled in by the caller, not inline.
- Texts used with `innerHTML` may contain `<b>`, `<i>` and `&amp;`; plain `textContent` texts may not.
- Static elements use `data-i18n="key"` in `index.html` (filled by `translateStatic()` in `main.ts`);
  dynamic ones call `t('key', params)`. Plurals: `plural('placesFound', n)` with `...One/Few/Many` keys.
- German: informal *du*, imperative singular (*Flieg*, *Folge*).
- Tone: short and friendly, for children. Dutch place names stay Dutch in every language.

Check with `npx tsc --noEmit -p .` and, for visible texts, the `check-ui` skill with `--lang sr-Cyrl`.
